#  Sorteador de Pelada — UC15 TI

Aplicação web para sortear times equilibrados de futebol amador por nível técnico e controlar o ranking de artilharia da galera de forma dinâmica e simples.

##  Funcionalidades
- **Cadastro de Jogadores:** Com nivelamento por estrelas (1 a 5).
- **Sorteio Equilibrado:** Divisão de times baseada na soma das habilidades.
- **Menu Dinâmico de Artilharia:** Seleção restrita apenas aos jogadores já cadastrados.
- **Ranking Visual:** Destaques automáticos para o TOP 3 (Medalhas de Ouro, Prata e Bronze).
- **Persistência de Dados:** Uso de `localStorage` para não perder os dados ao fechar a página.

##  Tecnologias Utilizadas
- **HTML5** (Estrutura semântica)
- **CSS3** (Design responsivo e Flexbox)
- **JavaScript ES6+** (Lógica de sorteio, validações e manipulação de DOM)
- **Git & GitHub** (Versionamento)
